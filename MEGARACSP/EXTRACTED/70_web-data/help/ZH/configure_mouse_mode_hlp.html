滑鼠模式

客戶端的 KVM Client (JViewer) 會負青處理從客戶端到遠端系統的滑鼠事件， 滑鼠會使用以下三種模式中的一種。 只有 '管理員' 有權限修改這個配置。
  • - 相對滑鼠模式
  • - 絕對滑鼠模式
  • - 其它滑鼠模式

用途

相對滑鼠模式

相對模式會計算滑鼠的相對位移量並傳送到伺服器，要選擇此模式請點選“ 將模式設置為相對”選項。

絕對滑鼠模式

絕對模式會將本地端滑鼠的絕對位置傳送到伺服器，要選擇此模式請點選“ 將模式設置為絕對“，建議伺服器為 Windows 或較新版的 Linux 使用。

其它滑鼠模式

其它模式會計算本地滑鼠在中心位置的位移量並傳送到伺服器。
伺服器為 SLES 11 建議使用此模式。

儲存

點選 '儲存' 以儲存變更。

重置

點選 '重置' 以重置之前的變更。
