NCSI

此頁面是用來配置 NCSI 設定。

用途

目前的 NCSI 模式

此欄位會顯示目前的 NCSI 模式。

設定 NCSI 模式為自動容錯移轉模式

選擇這個按鈕將會改變 NCSI 模式為自動容錯移轉模式。

設定 NCSI 模式為手動切換模式

選擇這個按鈕將會改變 NCSI 模式為手動切換模式，

NCSI 介面

下拉式選單中將會列出支援的介面名稱，請選擇你的配置 NCSI 設定的介面名稱。

Channel Number

為已選擇的介面名稱配置 channel number。

Package ID

為已選擇的介面名稱配置 package ID。

儲存

點選 '儲存' 以儲存變更。

重置

點選 '重置' 以取消變更。
