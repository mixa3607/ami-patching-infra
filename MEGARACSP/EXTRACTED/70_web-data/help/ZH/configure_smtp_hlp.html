SMTP

此頁用來設定 SMTP 配置。
用途

LAN Channel 編號

選擇 SMTP 要使用的LAN Channel。

寄件者位址

輸入 SMTP 伺服器上有效的 '寄件者位址'。

電腦名稱

輸入 '電腦名稱'。
  • - 電腦名稱是一個最長為 15 個字母數字的字串。
  • - 不允許使用空白，特殊字元。

主要 SMTP 伺服器

列出主要 SMTP 伺服器的配置。

支援 SMTP

點選此選項以啟用 BMC 對 SMTP 的支援。

Port

指定 SMTP 埠號。
  • - 預設的埠號為 25。
  • - 埠號的範圍從 1 到 65535。

伺服器位址

輸入 SMTP 伺服器的 'IP 位址'。此為必填欄位。
  • - IP 位址是由 4 組數字所組成並以逗點分開，例如："xxx.xxx. xxx.xxx"。
  • - 每一組數字的範圍由 0 ～ 255。
  • - 第一組數字不能為 0。
伺服器位址支援以下格式:
  • - IPv4 位址格式。
  • - IPv6 位址格式。

SMTP 伺服器要求身份驗證

點選此選項以啟用 SMTP 伺服器認證。
提醒：SMTP 伺服器認證支援以下方式：
  • - CRAM-MD5
  • - LOGIN
  • - PLAIN
如果 SMTP 伺服器不支援以上任何一種認證方式，使用者會收到錯誤訊息： "Authentication type is not supported by SMTP Server"

使用者名稱

輸入使用者名稱以存取 SMTP 帳戶。
  • - 使用者名稱為 4 到 64 個字母數字，可以使用點號（.），連字符號（-）和底線（_）。
  • - 開頭必需要是字母。
  • - 不允許使用其它特殊字元。

密碼

輸入 SMTP 使用者帳戶的密碼。
  • - 密碼至少要有 4 個字元長。
  • - 不允許使用空白鍵。
提醒：此欄位不允許超過 64 個字元。

啟用 STARTTLS 支援

點選此選項以啟用 SMTP 用戶端的 STARTTLS 支援。
  • SMTP CA 憑證檔案: 包含可信任的CA證書的檔案。
  • SMTP 憑證檔案: 客戶端 certificate 檔案。
  • SMTP 私密金鑰：客戶端的私鑰檔案。

次要 SMTP 伺服器

列出次要 SMTP 伺服器的配置。此為可選欄位。
如果主要 SMTP 伺服器不能正常工作，將會試著使用次要 SMTP 伺服器。

儲存

點選 '儲存' 以儲存配置。

重置

點選 '重置' 以重置配置。
