映象檔傳輸協定

此頁面用來配置上傳韌體映象檔時所使用的協定。

用途

協定類別

上傳韌體映象檔到 BMC 時所要使用的協定。

伺服器位址

儲存韌體映象檔的伺服器位址。同時支援 IPv4 和 IPv6。
  • - IPv4 位址是由 4 組數字所組成並以逗點分開，例如： "xxx.xxx.xxx.xxx。
  • - 每一組數字的範圍由 0 ～ 255。
  • - 第一組數字不能為 0。
  • - IPv6 位址是由 8 組 16 進位的數字組成 並以分號來分開，例如： "xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx:xxxx".
  • - Hexadecimal digits are expressed as lower-case letters.

映象檔名稱

映象檔在 TFTP 伺服器上的檔案名稱。

重試次數

傳輸失敗之後所要重試的次數。 重試次數的範圍由 0 ～ 255。

儲存

點選 '儲存' 來儲存設定。

重置

點選 '重置' 來重置已變更的設定。
