DNS

此頁面用來設定設備上的主機名稱和網域名稱伺服器。

用途

網域名稱伺服器設定

DNS 服務

點選複選框來啟用 DNS 服務的設定。

主機配置

主機設定

選擇自動設定主機或手動設定主機。

主機名稱

如果選擇自動設定，此欄位會顯示設備的主機名稱。 如果選擇手動設定，請在此欄位指定設備的主機名稱。
  • - 名稱的長度為 1 ～ 63 個字母數字。
  • - 允許使用特殊字元如連字號（-）和底線（_）。
  • - 開頭或結尾不允許使用連字符號'-'。
提醒： 如果主機名稱包函任何底線（_）， IE 瀏覽器功能將會不正常。

註冊 BMC

選擇 BMC 的網路端口來與DNS設置進行註冊。
點選複選框來啟用選擇 BMC 的網路端口來與DNS設置進行註冊。
  • Nsupdate - 選擇 'Nsupdate'選項來使用 nsupdate 應用程式跟 DNS 伺服器註冊。
  • DHCP Client FQDN - 選擇 'DHCP Client FQDN'選項來使用 DHCP 選項 81 跟 DNS 伺服器註冊。
  • Hostname - 選擇 'Hostname' 選項來使用 DHCP 選項 12 跟 DNS 伺服器註冊。
NOTE: 如果 DHCP 客戶的 FQDN 選項不支援 DHCP 伺服器,那 Hostname 選項應該要被選。

網域名稱設置

網域設定

如果網域的介面是 multiLAN 通道，此下拉式選單列出了網域的介面 是手動， v4 或 v6，

網域名稱

如果選擇自動設定，此欄位會顯示設備的網域名稱。 如果網域設定選擇手動設定，請在此欄位指定設備的網域名稱。

網域名稱伺服器配置

網域名稱伺服器設定

此下拉式選單列出了 DNS 介面為手動或其它 LAN 介面。

IP 優先權

如果 IP 優先權是 IPv4，將會有2個 IPv4 網域名稱伺服器和1個 IPv6 網域名稱伺服器。如果 IP 優先權是 IPv6，將會有2個網域名稱伺服器 和1個 IPv4 網域名稱伺服器。
提醒： 此欄位不接受手動設定。

網域名稱伺服器 1, 2 & 3

指定網域名稱伺服器 (Domain Name System) 位址給 BMC.
  • - IP 位址是由 4 組數字所組成並以逗點分開，例如: "xxx.xxx.xxx.xxx".
  • - 每一組數字的範圍由 0 ～ 255。
  • - 第一組數字不能為 0。
網域名稱伺服器位址可以支援：
  • - IPv4 位址的格式。
  • - IPv6 位址的格式。
提醒： 只允許使用 Global IPv6 位址。

儲存

點選 '儲存' 以儲存變更。 您將會登出網頁介面並需要再次登入。
