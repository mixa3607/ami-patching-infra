點選 ' 按鈕將會 開始下載 jviewer.jnlp 檔案，下載完成並啟動之後會顯示 Java Redirection （JViewer） 視窗。

感測器監測

顯示設備上所以的感測器資訊，例如狀態，名稱，值，和狀態圖示，以及 連接到感測器頁面的連結。目前的讀數會由類比的感測器來顯示，但是事件狀態會由在讀數區的離散感測器來顯示。
感測器有 3 種可能的狀態如下：
  • - 綠點表示正常狀態。
  • - 黃色感嘆號表示警告狀態。
  • - 紅色的X表示嚴重狀態。
可使用放大鏡進一步了解感測器細部資訊
