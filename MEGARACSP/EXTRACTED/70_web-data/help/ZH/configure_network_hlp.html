網路

此頁面用來對可使用的 LAN Channel 做配置。

用途

LAN 介面

選擇想要設定的 LAN 介面。

LAN 設定

點選此選項來對所選擇的 LAN 介面啟用支援。

MAC 位址

此欄位顯示所選擇的 LAN 介面的 MAC 位址（唯讀）。

IPv4 配置

列出了 IPv4 的配置設置。

IPv4 設定

點選此選項來對所選擇的 LAN 介面啟用 IPv4 支援。

自動取得 IP 位址

啟用 '使用 DHCP' 以使用動態主機設定協定（DHCP）來動態配置 IPv4 位址。

IPv4 位址，子網路遮罩，預設閘道

如果未啟用動態主機設定協定（DHCP），請為所選擇的介面配置靜態 IPv4 位址， 子網路遮罩和預設閘道。
  • - IP 位址是由 4 組數字所組成並以逗點分開，例如： ”xxx.xxx.xxx.xxx“。
  • - 每一組數字的範圍由 0 ～ 255。
  • - 第一組數字不能為 0。

IPv6 配置

列出了 IPv6 的配置設置。

IPv6 設定

點選此選項來對所選擇的 LAN 介面啟用 IPv6 支援。

自動取得 IP 位址

啟用 '使用 DHCP' 以使用動態主機設定協定（DHCPv6）來動態配置 IPv6 位址。

IPv6 位址

對所選擇的網路介面配置靜態 IPv6 位址。

子網路前綴長度

指定 IPv6 的子網路前綴長度。
  • - 子網路前綴長度範圍由 0 ～ 128。

VLAN 配置

列出了 VLAN 的配置設置。

VLAN 設定

點選此選項來對所選擇的 LAN 介面啟用 VLAN 支援。

VLAN ID

指定 VLAN 的 ID。
  • - VLAN ID 範圍由 2 ～ 4094。
提醒： 在重置 VLAN 配置之前，VLAN ID 並不會更改。
VLAN ID 0, 1, 4095 皆為保留值。

VLAN 優先權

指定 VLAN 的優先權。
  • - 優先權範圍由 0 ～ 7。
提醒： 7 是最高的優先權。

儲存

點選 '儲存' 以儲存變更。 系統將會提示您登出目前的 UI，並且在新的 IP 位址重新登入。

重置

點選 '重置' 以重置所有變更。
