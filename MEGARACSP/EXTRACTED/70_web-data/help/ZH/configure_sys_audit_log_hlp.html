系統和稽核記錄設置

此頁用來設定系統和稽核記錄配置。

用途

系統日誌

點選 '啟用' 選項以啟用系統日誌。

日誌類型

選擇系統日誌的日誌類型將會儲存在本地檔案或遠端伺服器，如果是本地檔案 將會儲存在 /var/log/。

檔案大小

如果選擇本地日誌，請指定檔案大小，以 byte 為單位。
  • - 檔案大小的範圍從 3 到 65535。

Rotate Count

如果日誌資訊超過指定的檔案大小，舊的日誌檔案將會基於 Rotate Count 被 移到備份檔案。如果 Rotate Count 為 0，舊的檔案將會被永遠清除。
  • - 範圍從 0 到 255。

伺服器位址

指定遠端伺服器位址來記錄系統事件。 伺服器位址支援以下格式：
  • - IP 位址（IPv4 或 IPv6 格式）。
  • - 完整網域名稱FQDN（Fully qualified domain name）格式。

稽核記錄

點選 '啟用' 選項以啟用稽核日誌。

儲存

點選 '儲存' 以儲存變更。

重置

點選 '重置' 以重置變更。
