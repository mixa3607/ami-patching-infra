Triggers Configuration

Configure which event on the page will trigger the auto-video recording option to start.

Actions

Event List

You can check/uncheck a box to add/remove that trigger for your system.

Save

Click 'Save' to save any changes made.
NOTE:
  • KVM service should be enabled (under 'Configuration -> Services') to perform auto-video recording.
  • The date and time should be in advance to the system date and time.

Reset

Click 'Reset' to reset the modified changes.
