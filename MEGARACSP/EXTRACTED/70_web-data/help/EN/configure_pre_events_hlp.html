Pre-Event Video Recording

This page is used to configure the Pre-Event Video Recording informations. To modify this configurations, you must be an Administrator.

Actions

Video Quality

Choose the video quality from the drop-down list to adjust the Pre-event boot/crash record video.

Compression Mode

Select the Compression Mode from the drop-down list that consists of various types of compression modes for Pre-event trigger videos.

FPS

Choose the FPS to recored the number of frames per second.

Video Duration

Choose this to set the time duration of the video that needs to be recorded.

Save

Click 'Save' to save the configured settings.

Reset

Click 'Reset' to re-adjust the modified changes.
