BMC Recovery

This page is used to configure BMC Recovery settings.

Actions

Force Recovery

Choose Enable/Disable to start auto-recovery immediately at next reboot.

Boot Retry Count

Enter the number of retries to reset the BMC, before entering into recovery if BMC Boot failure occurs. Boot Retry count ranges from 1 to 5.
NOTE: By default the Boot Retry count is mentioned as 2.

Recovery Retry Count

Enter the number of retries to recover firmware image during the recovery process. Recovery Retry count ranges from 1 to 5.
NOTE: By default the Recovery Retry count is mentioned as 3.

Server Address

Address of the server where the firmware image is stored.
  • - IP Address made of 4 numbers separated by dots as in "xxx.xxx.xxx.xxx".
  • - Each number ranges from 0 to 255.
  • - First number must not be 0.

Image Name

Enter the Image Name to edit the default recovery image name on TFTP server. NOTE: By default the image name is mentioned as rom.ima.
  • - Image name should contain only 5 Alpha numeric characters.
  • - If you enter new filename, enter the filename without extension (.ima)

Save

Click 'Save' to save the configured settings.

Reset

Click 'Reset' to reset the modified changes.
